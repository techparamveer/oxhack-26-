# Sheep — agent guide

Native SwiftUI iOS 17+ app for OxHack '26. **Spec (in priority order):** `docs/BUILD_PROMPT.md` → `docs/MVP_PLAN.md` → `docs/GEMINI_PROMPTS.md`. Read the sections relevant to your step before coding.

## Hard rules
- **No entitlements, ever**: no FamilyControls / ManagedSettings / DeviceActivity / App Groups / push / iCloud / Keychain sharing. Must run on Simulator + free Personal Team. No third-party packages (that includes supabase-swift).
- **Backend = Supabase** (project `wfrlvenjytnowvjuzgom`, code in `supabase/`): the `gemini` Edge Function proxies Gemini (key lives in the Supabase secret `GEMINI_API_KEY`; Flash allowlist; per-user rate limit via `consume_gemini_quota()`), anonymous auth, and fire-and-forget background sync of events / memory files / sessions / daily scores (`Sheep/Services/Supabase/`: hand-rolled URLSession client, session in UserDefaults, persisted retry queue). The device stays the source of truth and **offline must still fully work**: never await Supabase on a UI path (only `GeminiClient` does, inside its timeout); feed data through the `SupabaseSync.shared` hooks, not the client. New tables: a migration in `supabase/migrations/`, RLS `to authenticated` with `(select auth.uid()) = user_id`, explicit least-privilege grants.
- **Nunito only, never thin**: every `Text` uses a `Theme` font (`Theme.wordmark/score/display/title/headline/messageHeadline/pillNumber/modeLabel/rowTitle/body/bodyBold/bodySmall/label/labelBold/meta/caption/captionMeta/tab` or `Theme.nunito(size, weight:)`). **Minimum weight 400** — the user rejected thin type. Never `.font(.body)`, `.font(.system…)` for text, `Font.custom("Nunito")`, or `.fontWeight(.light/.thin/.ultraLight)`. Timer digits: `Theme.display.monospacedDigit()` + `.tracking(Theme.Tracking.display)`.
- **Design = Paper file "Sheep App"** (fileId `01M5Q56NPJ6C87X30DZ16SE70S`, artboards `00 Home — Normal`, `01 Home — Focus`, `02 Home — Rest`, `03 Settings`) + MVP_PLAN "Design". Read exact values with the Paper MCP (`get_jsx`, `get_computed_styles`), never eyeball. Palette "foggy field": `Theme.background` (fog #ECEDEB), `Theme.surface` (white), `Theme.text`, `bodyText`, `secondary`, `tertiary`, `outline`, `hairline`, `scoreUp`, `scoreDown`. Mode accent (`mode.accent`; text on it = `mode.onAccent`, Play = ink) ONLY for mode label + dot, active pill outline, primary button, timer ring. No gradients (except the nudge scrim), no shadows, no glass. **White rounded surfaces (`Surface`, radius 24) only for the Home message card, Settings groups and the tab bar**; everything else sits flat on fog, separated by whitespace or `Hairline()`. One `PrimaryButton` per screen (hugging 56 pt pill, optional icon); secondary = `TextButton`. Icons: SF Symbols `.semibold` (1.8–2 pt stroke look). `Screen(title:)` for chrome, 24 pt margins (cards 16), 8 pt grid (`Theme.space(n)`), springs ≤0.4 s (`Theme.spring`). Short copy. Must look right in dark mode.
- Hero sheep art lives in `Sheep/Assets.xcassets/Sheep/` (vector image sets) and is drawn by `SheepView(woolStage:size:mode:xp:)`: awake = no mode, focus = reading, rest = sleeping, play = controller. ⚠️ The controller sheep asset is missing (the exported PNG was blank) — Play falls back to awake until the user re-adds it.
- **Gemini**: every call goes through `GeminiClient.shared.generate(T.self, prompt, fallback:)`. Put each prompt in its own file `Sheep/Services/Prompts/<Name>Prompt.swift` with: system text copied verbatim from GEMINI_PROMPTS.md, a user-template builder, the schema as a `JSONValue` literal (lower-case types are fine — the client normalises), temperature, a `Codable` response struct and a **hardcoded fallback** that reads naturally offline. Fill `{{MEMORY}}` with `MemoryContext.build(for:)`. Timeout 3 s (consolidator 15 s). The client tries Supabase proxy → direct key (dev only) → fallback, all inside that one budget; nothing configured → fallback instantly, so the full demo must work offline.
- **Events**: log with `EventLog.shared.append(SheepEvent(type: …))` using the fields in GEMINI_PROMPTS "Event log format". Never store DM/post content — only app, section/path, timings, user's typed answers.
- **Persistence**: `AppState` (UserDefaults JSON) + files under `AppPaths`. No Core Data/SwiftData.

## Project layout
- `project.yml` (XcodeGen) generates `Sheep.xcodeproj`, which is committed. Both targets use **synchronized folders**: any file you add under `Sheep/` or `SheepTests/` is compiled automatically — do NOT edit `project.pbxproj` or `project.yml` unless truly necessary (if you must: edit `project.yml`, run `xcodegen generate`, commit both).
- `Config/Info.plist` (outside the synced folder on purpose). URL scheme `sheep` and `UIAppFonts` are already there.
- Shared contracts from the scaffold: `AppState`, `Router`/`Route`, `Theme`, `Components.swift`, `Mode`, `WrappedApp`/`AppSection`, `FocusSession`/`RestSession`/`PlaySession`/`SessionOutcome`, `Progress`, `EventLog`, `GeminiClient`, `Persona`/`PromptClock`, `NotificationService`, `MemoryContext` (stub), `ScrollMonitor` (stub), `Policy` (stub), `DevActions`.
- Placeholder screens live one-per-file in `Sheep/Views/Placeholders/`. When you implement one, DELETE its placeholder file and create the real one (same type name) so `RootView` routing keeps working.
- Contracts to keep: `XPRules` (all XP amounts), `MemoryStore` (list/read/write/delete/historySnapshotCount), `MemoryConsolidator.shared.run(reason:) async -> [String]` (learned), `MemoryContext.build(for:)`, `ScrollMonitor` (`ingest`, `didNavigate`, `didLeaveWrapper`, `pendingIntervention`), `InterventionOverlay(request:)`, `Policy`.
- Keep edits to shared files (AppState, Router, SheepApp, HomeView, DevMenuView, Components, EventLog, GeminiClient) small and additive — other agents are editing in parallel. Prefer new files/extensions.

## Build & test
Use your OWN simulator so parallel agents don't collide:
```sh
SIM="Sheep-$(basename "$PWD")"
xcrun simctl create "$SIM" com.apple.CoreSimulator.SimDeviceType.iPhone-17-Pro com.apple.CoreSimulator.SimRuntime.iOS-27-0 2>/dev/null || true
xcodebuild -project Sheep.xcodeproj -scheme Sheep -destination "platform=iOS Simulator,name=$SIM" -derivedDataPath .build/DerivedData test 2>&1 | grep -E "error:|warning: .*Sheep/|failed|Executed|SUCCEEDED|FAILED"
```
Screenshot: `xcrun simctl boot "$SIM"; xcrun simctl install "$SIM" .build/DerivedData/Build/Products/Debug-iphonesimulator/Sheep.app; xcrun simctl launch "$SIM" com.oxhack.sheep; xcrun simctl io "$SIM" screenshot .build/shots/<name>.png`. Delete your simulator when done (`xcrun simctl delete "$SIM"`).

Tests: XCTest in `SheepTests/<Feature>Tests.swift`, `@testable import Sheep`. Test pure logic (policy, thresholds, XP, memory parsing, prompt fill, fallbacks). Use temp dirs (`AppPaths.root = tmp`, `EventLog(fileURL:)`) and `UserDefaults(suiteName:)` — never the real Documents/defaults.

## Git / PRs
- Branch `feat/<step-name>` from latest `origin/main`. Small focused commits. Build + tests green before pushing.
- `gh pr create --base main` with a body: what/why, how to verify in the simulator, test results, screenshots paths if any. End PR body with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`; end commits with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Before handing back: `git fetch origin && git rebase origin/main`, rebuild, re-test, force-push with lease.
- `Config/Secrets.xcconfig` is git-ignored — never commit a key. It holds `SUPABASE_HOST` (bare host: xcconfig treats `//` as a comment), `SUPABASE_ANON_KEY` (publishable key only, never the secret key) and an optional dev-only `GEMINI_API_KEY`. Backend checks: `deno test supabase/functions/gemini/`.
